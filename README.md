# Rick and Morty App

Aplicacion web interactiva que muestra un catalogo de personajes de Rick and Morty. Construida con React, Vite y React Router.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## Instalacion y uso

```bash
npm install
npm run dev
```

La aplicacion abrira en http://localhost:5173

## Scripts

- `npm run dev` - Inicia servidor de desarrollo
- `npm run build` - Genera version de produccion
- `npm run lint` - Ejecuta ESLint
